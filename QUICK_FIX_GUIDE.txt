DATABASE PERSISTENCE (IMPORTANT!):

Your app uses SQLite. On Vercel, data resets on each deploy.

  Option A: Keep SQLite (data resets) → No setup needed
  Option B: Use Vercel Postgres → Set up in Vercel Storage tab
  Option C: External DB (Neon, Supabase) → Get PostgreSQL URL, set as env var

For persistent data, use Vercel Postgres (easiest):
  1. Vercel Dashboard → Storage → Create Database → Postgres
  2. Done! (Auto-configured via DATABASE_URL env var)

TROUBLESHOOTING:

Q: "Build still fails"
A: Did you push all changes? Check git status, git add ., git push

Q: "Form still says CSRF missing"
A: Check Vercel build log. If build passed, clear cookies + hard refresh

Q: "Timeout errors"
A: Increase maxDuration in vercel.json (currently 30s, max 60s for Pro)

Q: "Data disappeared after redeploy"
A: Yep, SQLite on Vercel doesn't persist. Switch to Postgres.
